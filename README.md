# Vira AI — public site

Static public site for **Vira AI**, an AI-assisted studio that creates short educational videos with a consistent animated presenter.

Live: https://pcostabuxeda-crypto.github.io/vira-ai/

## Pages
- `index.html` — home
- `terms.html` — terms of service
- `privacy.html` — privacy policy

## Run locally
No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy
GitHub Pages serves `main` automatically (`.nojekyll` disables Jekyll processing). Changes go through a pull request.
